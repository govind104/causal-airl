# Causal Inverse Reinforcement Learning for Robust Reward Recovery (GridWorld)

This repository contains all code, experiments, and visualisations for the MSc dissertation titled:

**"Causal Inverse Reinforcement Learning for Robust Reward Recovery"**

## 🧠 Overview

This project explores causal and deep variants of inverse reinforcement learning (IRL) in **discrete GridWorld**. We evaluate classical baselines (Ng-Russell IRL, MaxEnt IRL), adversarial models (AIRL), and a novel **Causal-AIRL** framework that infers latent confounders during reward learning.

* Methods: **Ng–Russell**, **MaxEnt**, **AIRL**, **Causal-AIRL**
* Experiments (8): baselines, AIRL/CAIRL **hparam sweeps**, AIRL/CAIRL **scenario sweeps**, **confounded**, **generalisation**, **scaling**
* One-shot viz + tables:

  ```bash
  python -m visualisation.make_all --out results/figures
  ```

---

## Data provenance

* **All data are synthetic**, generated by the GridWorld env (`envs/`) and experiment drivers (`experiments/`).
* **Confounding**: the confounded setting (latent Z) and any **held-out** spatial masks are defined via configs in `configs/` and serialized (e.g., `env_data.json`) by the runners.
* No external datasets are required.

---

## What gets saved in a run?

Each run directory contains a subset of:

* `config.json`, `config_flat.json`
* `metrics.json` (e.g., `final_reward_correlation`, `final_env_steps`, `final_wall_time_sec`, …)
* `training_logs.json` (AIRL/CAIRL curves)
* `learned_reward.npy` / `learned_reward_map.npy`
* `policy.pt` (AIRL/CAIRL), `trajectories.npy` (if saved)
* `checkpoints/reward_iter_*.npy` (AIRL/CAIRL)
* `env_data.json` (terminals / held-out masks, if applicable)

## Reproducing experiments (order)

1. **Baselines**

   ```bash
   bash scripts/run_gridworld_baselines.sh
   ```
2. **Method hyperparameter sweeps**

   ```bash
   bash scripts/run_airl_hparam_sweep.sh
   bash scripts/run_causal_airl_hparam_sweep.sh
   ```
3. **Scenario sweeps** (γ, demos, slip, reward type)

   ```bash
   bash scripts/run_airl_scenario_sweep.sh
   bash scripts/run_causal_airl_scenario_sweep.sh
   ```
4. **Confounded GridWorld** (Z-confounding, invariance)

   ```bash
   bash scripts/run_confounded_gridworld.sh
   ```
5. **Generalisation** (cross-Z + held-out regions; includes slip)

   ```bash
   bash scripts/run_generalisation_test.sh
   ```
6. **Scaling (optional)** — compute vs grid size, incl. Ng/MaxEnt

   ```bash
   bash scripts/run_scaling_performance.sh
   ```

Notes:

* Scripts write under `results/...` (e.g., `results/airl_scenarios/...`, `results/generalization/...`; both `generalization`/`generalisation` are supported by viz).
* Seeds and env sizes are controlled via the provided configs.

## Visualisation (one shot)

Generate **all** figures & tables (auto-discovers runs by `metrics.json`):

```bash
python -m visualisation.make_all --out results/figures
```

This produces: ablation panels, training curves, reward heatmaps, policy fields, AIRL↔CAIRL reward diffs, invariance & violation maps, held-out overlays, cross-Z bars (split per-slip), tradeoffs (including **wall-time vs accuracy**), scaling plots, and **summary tables**.

* **Scaling plots** run if `results/scaling/perf.csv` exists.
* **Summary tables** use `results/validation/experiment_summary.csv` if present; otherwise the step is skipped.

## Claims ↔ experiments (quick map)

* **Demo efficiency & robustness (H1/H3):** scenario sweeps (γ, demos, slip, reward shaping) for AIRL/CAIRL
* **Causal robustness (H2):** confounded runs + invariance metrics (Causal-AIRL vs AIRL)
* **Generalisation (H4):** cross-Z bars and held-out overlays, per-slip
* **Baselines sanity:** Ng–Russell & MaxEnt qualitative + metrics
* **Compute:** scaling wall-clock vs size; tradeoffs include **env-steps** and **wall-time**; compute-vs-accuracy scatter (if scaling data exist)
